# Logos Pharos

| Arquivo                 | Uso                                                           |
| ----------------------- | ------------------------------------------------------------- |
| `logo-pharos.svg`       | **Oficial** — degradê. Padrão no tema claro                   |
| `logo-pharos-dark.svg`  | Tema escuro / fundo escuro (branco)                           |
| `logo-pharos-light.svg` | Chumbo `#383838`. Só caso a caso, quando o degradê não couber |

Regras do brandbook: 1º degradê, 2º branco; azul ou chumbo só caso a caso; preto absoluto evitar (a versão preta foi removida do pacote); mínimo 16 px; sem transparência; em redução extrema (sidebar recolhida) usar o símbolo "A".

Logos Alexandria (`isolada_*`) permanecem como marca da empresa. Claro: `isolada_colorido`. Escuro: `isolada_white`.
