# Símbolo "A"

Versões reduzidas da marca, para onde o logotipo não cabe (sidebar recolhida, avatar, favicon). Mínimo de 16 px.

| Arquivo                | Uso                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------ |
| `A_bg_gradiente.svg`   | "A" branco sobre quadrado em degradê. Funciona em qualquer fundo, inclusive o escuro |
| `A_bg_transparent.svg` | "A" em degradê, sem fundo. Para fundos claros                                        |
| `A_bg_wt.svg`          | "A" em degradê sobre quadrado branco                                                 |
| `A_azul.svg`           | "A" azul (`#034694`), sem fundo. Navegação monocromática no claro                    |
| `A_white.svg`          | "A" branco, sem fundo. Navegação monocromática no escuro                             |

No pacote, use `<AlexandriaLogo kind="symbol" />` de `@pharos-ds/theme-pharos/logo` (tons `gradiente`, `transparente`, `branco`, `azul` e `white`). Depois de alterar um arquivo aqui, rode `pnpm -F @pharos-ds/theme-pharos build:logos`.
